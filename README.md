# Скрапер

**Скрапер для сбора данных о криптовалюте с сайта 'https://www.coingecko.com/ru'.**

Скрапер реализован через графический интерфейс, который:

1. Выполняет сбор данных о криптовалюте (название, символ, цена, объём торгов, капитализация.)
2. Автоматически сохраняет собранные данные в базу данных SQLite
3. По запросу делает выгрузку данных из БД в файл формата .xlsx
4. Выполняет постороение и отображение графиков цены криптовалюты

---

## Установка

```bash
git clone https://github.com/VladimirUstinov5690/scraper_prj.git
cd <папка_проекта>
python -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows
pip install -r requirements.txt
```

# Использование

Запускается:

```bash
1. С помощью графического интерфейса: 
    python main_interface.py

2. Скрапинг без интерфейса, через консоль: 
    1. Переходим в дерикторию scrapper_dir
    2. python start_scrap.py
```

## 🖥 Основные элементы интерфейса

```bash
Кнопки:

Начать сбор данных — в фоновом режиме осуществляет сбор данных с сайта криптовалют (При запуске программы рядом с 
запускаемым файлом создаётся БД - crypto.db).

Закончить сбор данных — останавливает работу по сбору данных.

Выгрузить в Excel — выполняет выгрузку данных в Excel (При выполнении команды рядом с запускаемым файлом создаётся 
файл - cryptocurrency data.xlsx).

Построить график — при выполнении команды запрашивает символ криптовалюты (например - BTC), выполняет построение и 
отображение графика изменения цены во вгладке - График!

Вкладки:
Логи - отображаются действия происходящие в программе
График - отображается график изменения цены по указонному символу криптовалюты.

```
